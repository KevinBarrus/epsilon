# 第十六轮优化方案：迁移到行内视口

## 目标与边界

- 使用终端主屏幕和原生回滚区保存已展示的对话
- 底部只重绘当前活动内容、输入区域和状态栏
- 关闭应用级鼠标上报，恢复终端滚动、缩放和选区
- 保持模型、Agent Loop、工具、Session、上下文和持久化逻辑不变
- 不通过简单修改 `full_screen` 参数冒充完整迁移

## 最终数据流

```text
模型与工具事件
    ↓
界面事件处理
    ├── 已完成内容 → 终端主屏幕回滚区，只写一次
    └── 临时内容   → 底部行内视口，允许重绘
                         ├── 流式回复
                         ├── working / 工具运行状态
                         ├── 输入框或审批界面
                         └── 状态栏
```

## 步骤一：增加退出摘要

1. `run_chat()` 在界面结束并完成 Session 关闭后返回退出信息
2. 启动层负责在终端状态恢复后打印摘要，界面层不直接打印 shell 文本
3. 摘要格式统一为：

```text
Token usage (this run): total=... input=... cached=... output=...
To continue this session, run epsilon resume <session-id>
```

4. 用量只统计本次进程收到的真实 `UsageEvent`；未开启或服务端不支持真实用量时显示 `Token usage: unavailable`
5. `/delete` 删除会话后不打印恢复指引，Ctrl+D 和 `/quit` 正常打印
6. 增加退出摘要格式、Session ID 和无真实用量分支测试

## 步骤二：分离稳定历史与临时内容

1. 对话展示继续使用现有 `ConversationEntry`，但明确区分已完成条目和活动条目
2. 用户消息、最终模型回复和已完成工具结果属于稳定历史，只允许提交一次
3. 流式回复、thinking、working、spinner 和执行中的工具条目属于临时内容，只在底部视口重绘
4. 界面层维护“已提交边界”，禁止重复写出同一条目
5. Session 仍然是模型历史和持久化的唯一来源，终端回滚区只负责展示
6. 增加稳定条目只提交一次、临时状态不进入历史输出的测试

## 步骤三：实现行内视口输出

1. 将应用切换为非全屏模式，停止进入终端备用屏幕
2. 新增职责单一的历史输出组件，只负责把已完成条目写入终端主屏幕
3. 新会话的 Logo 和启动提示只展示一次；恢复会话时先按顺序输出历史，再启动底部交互视口
4. 当前活动回复留在底部视口；条目完成后写入回滚区并从活动区域移除
5. 长回复完成后必须完整进入回滚区，可通过普通滚轮和触摸板查看
6. 终端宽度变化由终端处理已提交历史的重排，应用只重绘底部活动区域
7. 增加新建会话、恢复会话、流式完成和终端退出后的输出顺序测试

## 步骤四：迁移底部交互组件

底部行内视口保留现有视觉顺序：

```text
当前活动回复或工具状态
输入框 / 审批或选择界面
状态栏
```

迁移时保持：

- Slash Command 列表的选择与滚动
- 输入框 ↑/↓、Enter、Ctrl+J、Esc、Ctrl+C 和 Ctrl+V
- 输入框 `↑ n more` 提示
- 工具审批、Skill 选择和通用选择器
- thinking、working、工具耗时和结果省略展示
- 状态栏现有的工作目录、模型、余额、用量、费用、上下文和复制提示

每迁移一种交互组件，先运行对应单元测试，再进入下一项。

## 步骤五：移除应用级鼠标与旧滚动实现

1. 设置 `mouse_support=False`，删除自定义鼠标协议启停代码
2. 删除 `SelectionPane`、对话区拖选高亮和自动复制回调
3. 删除 `ConversationView` 及应用内滚动、自动跟随和 PageUp/PageDown 状态
4. 删除 `/auto-copy` 命令、注册项和相关测试
5. 保留输入框内 Ctrl+C 复制；对话区选择与复制交给宿主终端
6. 更新启动提示，不再宣称应用管理 Ctrl+滚轮缩放

## 步骤六：调整语义受限的功能

### `/clear`

- 清空当前活动区域并开始新的显示段落
- 不清除 Session 历史
- 不删除进入应用前或已经写入回滚区的终端历史

### 工具结果展开

- 尚在活动区域的工具结果可以原地展开
- 已写入回滚区的工具结果不做原地重写
- 完整内容仍可通过再次输出或导出查看

## 测试计划

- 退出摘要：真实用量、无用量、恢复指引和删除会话
- 历史输出：顺序正确、每条只写一次、临时帧不落入回滚区
- 流式输出：完成后完整写入历史，取消和错误内容保持现有语义
- Session 恢复：历史只输出一次，输入框定位到底部
- 交互回归：Slash Command、审批、选择器、输入历史和输入框多行滚动
- 业务回归：工具、持久化、上下文压缩和异常处理测试不受影响
- 手动终端验证：普通滚轮、触摸板、Ctrl+滚轮、原生选区和 Ctrl+D 退出

## 验收标准

- Ctrl+D 退出后，本次对话仍保留在当前终端回滚区
- 退出后展示真实的本次运行用量或明确标注不可用
- 退出后展示正确的 `epsilon resume <session-id>` 指引
- 普通滚轮和触摸板可以查看完整历史
- Ctrl+滚轮由宿主终端完成缩放
- ↑/↓ 保持输入框编辑和输入历史语义
- 对话区不再启用应用级鼠标选区和自动复制
- `/auto-copy` 已删除，输入框 Ctrl+C 仍可使用
- 状态栏已有信息和审批、工具、Slash Command 展示保持正常
- 完整测试集通过
