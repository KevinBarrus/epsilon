# 问题 21：SWE-bench 评测缺少运行环境引导

## 问题一：模型只能猜测评测工作区与工具约定

真实 SWE-bench 评测的任务提示词只包含 Issue 和通用修改约束，没有说明本次临时工作区、`run_command` 的工作目录、文件工具路径规则和工作区不含 Git 历史等事实。

实际失败轨迹显示模型会猜测 `/workspace`，或把文件传给仅接受目录的 `search_files`。这些无效调用会消耗工具回合，并让模型在错误环境假设下继续探索。

## 问题二：工具路径错误缺少下一步操作指引

`search_files` 在路径不是目录时仅返回通用错误，模型不知道应改用已有目录，也不知道仓库根目录可以传 `"."`。

## 问题三：真实评测结果无法标识环境引导版本

同一任务重跑后，结果变化可能来自提示词、模型、网络或代码。当前结果没有记录评测环境契约版本，不能清晰归因。
