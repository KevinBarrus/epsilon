# 驱逐实验 E2：参数修复与离线复验

> 状态：参数修复已完成；离线扫描未找到满足实验条件的阈值，因此按工单约束停止，没有发起付费 E2。

## 一、修复内容

本轮保留原有 Artifact Store、驱逐回放和 JSONL 记录格式，只调整驱逐决策：

1. `EVICTION_TARGET_RATIO = 0.65`：越过阈值后一次降到阈值的 65%，或降到没有候选为止；一次触发仍只生成一条原子 `EvictionRecord`。
2. `EVICTION_MIN_SAVINGS_TOKENS = 4_000`：先在内存中计算完整驱逐计划，预计节省不足 4,000 token 时不写 artifact、不生成驱逐记录。
3. `KEEP_RECENT_TOOL_OUTPUT_TOKENS = 16_000`：从最新工具输出向前累计 token，保护预算内的全部工具输出，不再按固定条数保护。
4. 默认驱逐阈值保持 `compaction_threshold // 2`，即当前默认预算下的 42,000 token；默认开关仍为关闭。

评测事件同时补充了两类诊断：实际驱逐记录 `tokens_before`、`tokens_after` 和降级条数；收益门槛拦截记录 `eviction_gate_rejected`。这些字段只用于评测统计，没有修改 `EvictionRecord` 的持久化结构。

单元测试覆盖迟滞目标、收益门槛、16k token 保护区、防抖和原有驱逐不变量。最终全量测试为 690 项通过。

## 二、离线扫描方法

扫描复用 E0 的完整 Session 历史，不调用模型。一次性脚本位于 `/tmp/epsilon-probes/replay_e0.py`，不进入仓库。

- 轨迹：`evaluation-results/long-task-E0/`
- Session：`2831ef0d-c478-43b7-925d-7db7cfe58721`
- 模型计数口径：`deepseek-v4-pro`
- 上下文实现：当前修复后的 `ContextManager`
- 正式扫描阈值：28k、32k、36k、40k、42k
- 选择规则：取预计触发 3～8 次的最低档

E0 自然上下文峰值与原报告一致：T1 为 27,841，T2 为 33,383，T3 及全局峰值为 42,717 token。

## 三、扫描结果

| 阈值 | 实际驱逐 | gate 拦截 | 降级工具输出 | 被拦计划最大预计节省 |
| ---: | ---: | ---: | ---: | ---: |
| 28,000 | 0 | 18 | 0 | 2,054 token |
| 32,000 | 0 | 18 | 0 | 2,054 token |
| 36,000 | 0 | 13 | 0 | 2,054 token |
| 40,000 | 0 | 9 | 0 | 2,054 token |
| 42,000 | 0 | 2 | 0 | 2,054 token |

为排除“只差一个更低阈值”的可能，又补扫了 20,000 和 24,000：两档同样均为 0 次驱逐、18 次 gate 拦截，最大预计节省仍为 2,054 token。

结果说明：在这条 E0 轨迹中，排除最近 16,000 token 的受保护工具输出后，剩余候选全部降级最多只能节省 2,054 token。该数值低于 4,000 token 收益门槛，所以阈值只会改变 gate 判定出现的时机，不会产生实际驱逐。

## 四、E2 决策

正式五档没有任何一档达到“预计触发 3～8 次”，因此没有可选的 E2 阈值。若继续运行原定长任务，实验组预计不会发生驱逐，结果只能复现 E0 附近的自然波动，无法检验迟滞区是否改善前缀缓存，也无法支持“驱逐净收益为正或为负”的结论。

按工单“离线扫描通过后再花钱”的约束，本轮停止在离线阶段：

- 不运行付费 E2；
- 不创建或改写 `evaluation-results/long-task-E2/`；
- 不改动 E0、E1 的任何历史数据；
- 驱逐默认保持关闭；
- 不执行“两次负结果后永久关闭”的分支，因为本轮没有形成第二次有效实验。

## 五、当前结论与后续边界

本轮能够确认的是：四项参数修复已经进入代码，且在 E0 轨迹上，`16k` 保护区与 `4k` 收益门槛会阻止低收益驱逐。它避免了 E1 那种频繁改写前缀的已知损失，但这不是“驱逐取得正收益”的证据。

若要继续验证驱逐净收益，应另开实验设计，使用能在保护区之外积累至少 4,000 token 可降级工具输出的更长任务；或者明确修改保护预算、收益门槛之一。前者改变评测载体，后者改变本工单固定参数，均不应在本轮为制造触发次数而临时调整。
