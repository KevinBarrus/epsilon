## 背景

## 第 0 步：确认两处修复（不花钱，先做）

1. **混合批次分区**：确认 `agent_loop.py` 在"串行批次"里把**连续的可并行工具并成一并发组**、写工具按序单独执行。
   - 补边界测试：批次 `[读, 写, 读]` → 两个并发组 + 一个串行；`[写, 写]` → 全串行；`[读, 读, 读]` → 全并发；
   - 断言 `ToolBatchEvent.execution_mode` 与各工具实际并发关系一致。
2. **`.npm`/`node_modules` 排除**：确认 baseline 的 `git add -A` **之前**已写入 `.git/info/exclude`。
   - 补测试：建一次 baseline，断言提交里**不含** `.npm/` 和 `node_modules/`。
3. **超时落盘**：确认超时被归类为 `TimeoutError` 并**写出 `result.json`**（含 goal 状态、已收到 token）。
   - 补测试：模拟墙钟到期，断言有结果文件落盘、不静默退出。
4. 全量测试通过（当前 746 项）。
