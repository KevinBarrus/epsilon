# 会话恢复交互实现计划

## 1. 目标

为已经完成的 Session + JSONL 持久化增加可用的会话恢复入口：

- 支持 `resume` 命令；
- 带 Session ID 时直接恢复；
- 不带 Session ID 时显示历史会话列表；
- 使用上下箭头选择，Enter 进入；
- 当前选中的会话显示为蓝色；
- 未选中的会话使用终端默认字体颜色；
- 恢复后一次性显示历史消息，不模拟流式输出。

## 2. 命令形式

在 `pyproject.toml` 增加命令行入口：

```toml
[project.scripts]
epsilon = "core.main:main"
```

命令行为：

```bash
epsilon              # 创建新会话
epsilon resume       # 打开会话选择器
epsilon resume ID    # 直接恢复指定会话
```

不再把 `--session-id` 作为主要入口，恢复功能统一归入 `resume` 子命令。可以保留旧参数作为兼容入口，但不新增第二套交互逻辑。

## 3. 会话列表

### 3.1 数据来源

继续使用当前的 JSONL 文件，不新增数据库和元数据文件：

```text
.epsilon/sessions/<session_id>.jsonl
```

`SessionStore` 新增列出会话的方法，返回最小的会话摘要：

- `session_id`；
- `title`；
- `updated_at`。

### 3.2 摘要生成

- 标题取 JSONL 中第一条用户消息；
- 标题去除换行并截断到固定长度；
- 没有用户消息时使用短 Session ID；
- 最近时间使用 JSONL 文件的修改时间；
- 按最近修改时间倒序排列；
- 文件损坏的会话不在列表中静默隐藏，应返回可识别的错误或跳过并显示警告。

这样无需改变现有消息记录格式，也不需要维护额外的会话索引。

## 4. 会话选择器

新增 `src/core/session_picker.py`，使用项目已有的 `prompt-toolkit` 实现独立选择界面。

界面行为：

- 上箭头：选择上一项；
- 下箭头：选择下一项；
- Enter：确认当前选中项并返回 Session ID；
- Esc：取消选择并退出恢复流程；
- 初始选中第一条最近会话；
- 选中的会话使用蓝色字体；
- 未选中的会话不指定颜色，使用终端默认字体颜色；
- 当前没有会话时显示提示并结束程序。

展示内容：

```text
↑/↓ 选择，Enter 进入，Esc 退出

> 修复登录接口的超时问题    2026-08-16 20:31    a12f8c4
  解释当前的上下文管理设计    2026-08-15 14:02    7bc91de
```

选择器只负责展示列表和返回选择结果，不负责读取 JSONL 和构造 Session。

## 5. 恢复后的界面

恢复流程：

```text
解析 resume 命令
  ↓
获取 Session ID
  ├── 命令中已提供 → 直接使用
  └── 未提供 → 打开 SessionPicker
  ↓
Session.restore()
  ↓
创建 ChatScreen
  ↓
按历史顺序一次性加入用户和模型消息
  ↓
滚动到最新消息
  ↓
等待用户继续输入
```

历史消息不模拟流式输出，因为这些内容已经完成生成。模拟流式输出会增加恢复等待时间，也会混淆“历史加载”和“模型生成”这两种状态。

恢复后的模型请求继续使用完整 Session 历史，新的消息会继续追加到原有 JSONL 文件。

## 6. 模块职责

### `src/core/session_store.py`

新增会话摘要列表能力，负责读取文件、提取标题和获取更新时间，不负责终端渲染。

### `src/core/session_picker.py`

只负责会话列表的键盘交互和颜色展示，返回选中的 Session ID，不负责 Session 恢复。

### `src/core/session.py`

继续负责 Session 恢复和消息追加，不负责选择器和终端渲染。

### `src/core/ui.py`

接收已经确定的 Session，并在创建 TUI 后将历史消息渲染到对话区，不负责会话选择。

### `src/core/main.py`

负责解析 `resume` 子命令，决定直接恢复还是打开选择器，再启动应用。

## 7. 实现顺序

1. 为 `SessionStore` 增加会话摘要数据结构和列表方法；
2. 新增会话摘要、标题截断和更新时间测试；
3. 新增 `SessionPicker`，实现上下移动、Enter、Esc 和蓝色选中态；
4. 为选择器增加键盘行为和颜色测试；
5. 将 `main.py` 改为支持 `resume [session_id]`；
6. 将恢复后的 Session 历史一次性渲染到 `ChatScreen`；
7. 增加带 ID 恢复、不带 ID 选择和恢复后继续对话测试；
8. 在 `pyproject.toml` 增加 `epsilon` 命令入口；
9. 运行完整测试集并手动验证选择器交互。

不修改 `screen.py` 的布局、滚动和输入快捷键实现，只通过现有 `ChatScreen.add_entry()` 加载历史消息。

## 8. 测试计划

### 会话列表测试

- 正确发现 `.epsilon/sessions/` 下的 JSONL 文件；
- 标题取第一条用户消息；
- 标题会去除换行并截断；
- 按更新时间倒序排列；
- 空会话使用 Session ID 作为标题；
- 文件损坏时不会产生无效摘要。

### 选择器测试

- 初始选中第一项；
- 上下箭头改变选中项；
- 选中项使用蓝色样式；
- 未选中项使用默认样式；
- Enter 返回正确的 Session ID；
- Esc 返回取消结果。

### 恢复流程测试

- `resume <session_id>` 直接恢复指定会话；
- `resume` 选择会话后恢复对应历史；
- 恢复后 TUI 按顺序显示历史消息；
- 恢复后新消息继续追加到原 JSONL 文件；
- 没有历史会话时显示提示并安全退出。

## 9. 验收标准

- 用户可以使用 `epsilon resume` 进入会话选择器；
- 用户可以使用上下箭头移动选择；
- 当前选中会话为蓝色，其他会话保持默认字体颜色；
- Enter 可以进入选中的会话；
- `epsilon resume <session_id>` 可以跳过选择器直接进入；
- 会话列表显示标题、最近时间和短 Session ID；
- 恢复后历史消息立即显示并定位到底部；
- 恢复后继续对话会追加到原会话文件；
- 不新增数据库、复杂索引和独立元数据文件；
- 完整测试集通过。
